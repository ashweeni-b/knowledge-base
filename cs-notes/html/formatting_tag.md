### Formatting Tags

1. Heading Tags

    - Heading tags are titles or subtitles to be displayed on the webpage
    - Defined with `<h1>` to `<h6>` tags
    - `<h1>` is the most important tag
    - `<h6>` is the least important tag
    - Search engines use these headings to index the structure and content of the web page
    - `<h1>` is used for page titles while `<h2>` is used for section titles and `<h3>` is used for sub-sections

    > Browser automatically add some white space before and after a heading

1. Paragraph Tag

    - Displays a paragraph always starting on a new line
    - Browser automatically add some white space (margin) before and after a paragraph
    - And also it removes any extra spaces and lines when the page is displayed

1. Horizontal Ruler

    - Defines thematic break in an HTML page displayed as a horizontal rule
    - Separates content or defines a change
    - `<hr>` is an empty tag

1. Line Breaks

    - Defines a line break
    - `<br>` is an empty tag

1. Pre Element

    - Solves the poem problem
    - Defines preformatted text
    - Text with the tags is displayed in a fixed-width font (usually Courier), and it preserves both spaces and line breaks

1. Bold Tag

    Defines bold text without any extra importance

1. Strong Tag

    - Defines text with stronger importance
    - Content inside is typically displayed in bold

1. Italic Tag

    - Defines a part of text in an alternated voice or mood
    - Content inside is typically displayed in italic
    - Often used to indicate technical term, phrase from another language, thought, etc.

1. Emphasized Tag

    - Defines emphasized text
    - Content inside is typically displayed in italic
    - Screen reader willl pronounce the content with an emphasis using verbal stress

1. Big Tag

    Defines content within in larger text

1. Small Tag

    Defines content within in smaller text

1. Mark Tag

    Defines content in makred or highlighted text

1. Delete Tag

    - Defines content deleted from a document
    - Broswers will usually strike a line through deleted text

1. Insert Tag

    - Defines content that has been inserted into a document
    - Broswers will usually underline inserted text

1. Subscript Tag

    - Text appears half a character below the normal line
    - Sometimes rendered in small font
    - Used for chemical formulae

1. Superscript Tag

    - Text appears half a character above the normal line
    - Sometimes rendered in small font
    - Use for footnotes
