### C Programming Language

- General purpose procedural language
- High-level, structured programming language
- Mother of all programming languages
- Developed by _Dennis Ritchie_ in 1972 at Bell Labs
- One of the first stable programming language
- Foundation of C\+\+, Java and Python
- Developed for writing the Unix operating system
- Designed for systems programming
- Provides low-level memory access while maintaining high performance and portability

#### Why C was developed?

- Before C programming was commonly done in assembly language, which was
    - Difficult to write
    - Difficult to debug
    - Machine dependent
    - Time consuming

- Dennis Ritchie developed C to make systems programming easier while still allowing efficient interaction with hardware
- Initially developed for Unix OS, but in current time it is used for the development of Embedded System, Real Time Algorithms and Operating System

#### Key Characteristics

1. General-purpose language
1. Procedural programming language
1. Compiled language
1. Strucutred programming language
1. Middle-level language (supports both high-level and low-level programming)
1. Portable across different systems
1. Fast execution
1. Efficient memory management using pointers

#### Features

1. Simple syntax
1. Rich set of operators
1. Functions
1. Pointers
1. Structures
1. Dynamic Memory Allocation
1. File handling
1. Standard library

#### Advantages

1. Fast execution
1. Efficient memory usage
1. Portable
1. Suitable for systems programming
1. Excellent foundation for learning programming

#### Disadvantages

1. No built in Object Oriented Programming

1. No automatic garbage collection <br />
    Automatically freeing memory that is no longer being used

1. Manual memory management <br />
    Programmer needs to allocate, access, update, free memory. Improper memory management leads to Memory leak, Double free, Dangling pointer and invalid memory access

1. Less type safety compared to many modern languages <br />
    Preventing invalid operations between incompatible data types
