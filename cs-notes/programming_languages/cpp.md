### C++ Programming Language

- General purpose, high-level, compiled programming language
- Has multiple paradigms
- Extension of C
- Developed by Bjarne Stroustrup in 1979 at Bell Labs but first released in 1982
- Adds object-oriented, generic and modern programming features while maintaining efficiency of C

#### Why C++?

As software becomes large procedural programming alone becomes harder to manage and so Bjarne Stroustrup developed C++ which supports:

- Better code organisation
- Reusability
- Abstraction
- Large-scale software development
- Control over system resources and memory
- Performance i.e. efficiency and speed

#### Key Characteristics

1. General purpose language
1. Compiled language
1. Multi-paradigm language
1. Supports procedural, OOP, generic and functional programming features

#### Major Features

1. Classes and Objects
1. Encapsulation
1. Inheritance
1. Polymorphism
1. Abstraction
1. Templates
1. Standard Template Library
1. Exception Handling
1. Operator Overloading

#### What type of language is C++ - High-level or Low-level?

C++ is a middle level language because it has features of both high-level and low-level language

Low-Level Language
- Direct memory access using pointers
- Manual memory management
- Close interaction with hardware
- Very fast execution
- Can work with system-level programming

High-level language
- Classes and OOP
- Templates
- STL
- Abstraction and reusable code
- Easier syntax compared to assembly

#### Advantages

1. High-performance
1. Supports multiple paradigms
1. Excellent for large software systems
1. Rich Standard Template Library
1. Good balance between abstraction and control

#### Disadvantages

1. Larger language with a steep learning curve
1. Manual memory management is still possible and requires care
1. Complex syntax compared to some modern languages
