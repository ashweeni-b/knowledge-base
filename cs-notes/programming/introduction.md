### Introduction to Programming

#### What is programming?

- Process of writing instructions that tell a computer to perform a specific task
- Process of designing, writing, testing, debugging and maintaining set of instructions, also known as _programs_
- Instructions are written in progamming language

#### Process of Programming

1. Problem Analysis - Understanding the problem to be solved
1. Algorithm Design - Developing a step-by-step solution
1. Flowchart or Pseudocode - Planning the programming logic
1. Coding - Writing the program
1. Compilation or Interpretation - Conversion of program into machine language
1. Testing and Debugging - Finding and fixing errors
1. Execution - Running the program
1. Maintenance - Updating and improving the program over time

#### Programming vs Coding

| Programming | Coding |
| ----- | ----- |
| Complete process of developing software | Process of writing source code |
| Includes problem-solving, design, coding, testing, debugging, and maintenance | Includes writing code and focusing mainly on syntax |
| Broader concept | Part of programming |

#### What is a programming language?

- Computer language used by programmers to communicate with computers
- A formal language used to write instruction or programs

#### Features of Programming Language

1. Has a well-defined syntax i.e. rules for writing code
1. Has semantics i.e. meaning to the instructions
1. Allows programmers to solve computational problems
1. Can be translated into machine language

#### Communication between programmer and computer

1. Programmer writes the program or source code in a programming language
1. The program is then passed to the language processors for conversion into machine code
1. The machine code is then executed by the computer
1. Once successful execution of the machine code, the output is generated by the computer

#### Examples of Programming Language

1. C - System programming and embedded systems
1. C++ - High performance applications and game development
1. Python - AI, Machine Learning, Data Science
1. Java - Enterprise and android applications
1. JavaScript - Interactive web development
